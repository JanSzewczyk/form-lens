# FormLens Studio

The web app of FormLens: it lists the form templates of the [FormLens API](../api/README.md) and is where
templates and extractions will be worked with. Next.js 16 (App Router, React 19, React Compiler),
Tailwind CSS 4 and the Szum-Tech Design System. It started from
[nextjs-szumplate](https://github.com/JanSzewczyk/nextjs-szumplate); see [docs/templates.md](../../docs/templates.md).

## Run it

From the repository root:

```bash
npm ci
cp apps/studio/.env.example apps/studio/.env.local   # FORMLENS_API_URL points at the API
npm run dev -w @form-lens/studio                      # http://localhost:3000
```

The API is optional for the page to load: without it the home page says the API is not available.

## How it talks to the API

`packages/api-client` is generated by Orval from `apps/api/openapi.json` and committed. Import it only from
server code, through `lib/formlens-api.ts`, which points the client at `FORMLENS_API_URL`:

```ts
import { listTemplates } from "~/lib/formlens-api";

const response = await listTemplates({ limit: 20 });
if (response.status === 200) response.data.items; // typed; other statuses are typed Problem Details
```

After the API changes: `make openapi` in `apps/api`, then `npm run generate -w @form-lens/api-client`.
`npx nx run api-client:generate:check` fails when the committed client is out of date.

## Checks

```bash
npx nx run-many -p studio api-client -t generate:check type-check biome:ci knip:ci test:unit build
```

Storybook (`storybook:build`, `test:storybook`) and Playwright (`test:e2e:ci`, after `build`) need browsers and
run separately. The image: `npx nx run studio:docker-build`.
