# FormLens

[![CI](https://img.shields.io/github/actions/workflow/status/JanSzewczyk/form-lens/ci.yml?branch=main&logo=githubactions&logoColor=white&label=CI)](https://github.com/JanSzewczyk/form-lens/actions/workflows/ci.yml)

FormLens reads scanned forms and PDFs with document models that run on your own machine, with no cloud calls, and
returns their text and the fields you ask for. This is the monorepo: the service, the web app and the client that
connects them. It is managed with [Nx](https://nx.dev).

| Folder | What | Stack |
| --- | --- | --- |
| [`apps/api`](apps/api/README.md) | **FormLens API**: parses documents, stores form templates, queues extractions | Python 3.15, FastAPI, uv, Docling, SQLite |
| [`apps/studio`](apps/studio/README.md) | **FormLens Studio**: the web app for templates and extractions | Next.js 16, React 19, Tailwind CSS 4, npm |
| [`packages/api-client`](packages/api-client) | TypeScript client of the API, generated by Orval from `apps/api/openapi.json` | Orval, fetch |

The Python package, its CLI and the image are still called `formlens`; `form-lens` is only the repository.

## Start

You need Node 24 (`.nvmrc`), [uv](https://docs.astral.sh/uv/) and, for the images, Docker.

```bash
npm ci                                  # the Studio, the client and Nx
npx nx run api:install                  # uv sync --locked in apps/api
npx nx graph                            # how the projects relate
```

Run the API (it needs the document model: `make download-models` in `apps/api`, see its README) and the Studio:

```bash
npx nx run api:serve                    # http://localhost:8000
npm run dev -w @form-lens/studio        # http://localhost:3000, reads FORMLENS_API_URL
```

## Commands

| Command | What |
| --- | --- |
| `npx nx run api:check` | Everything `make check` runs in `apps/api`: format, lint, types, import contracts, tests, OpenAPI drift |
| `npx nx run-many -p studio api-client -t generate:check type-check biome:ci knip:ci test:unit build` | The Studio checks |
| `npx nx affected -t check type-check` | The checks of the projects a change touches (`NX_BASE=origin/main`) |
| `npx nx run api:openapi` | Regenerate `apps/api/openapi.json` |
| `npm run generate -w @form-lens/api-client` | Regenerate the client after the API contract changed |
| `npx nx run api:docker-build`, `npx nx run studio:docker-build` | Build the images |

`apps/api` keeps its Makefile as the single source of truth; the Nx targets call it. Run the API's own commands
(`make ...`, `uv ...`) from `apps/api`.

## CI and releases

`.github/workflows/ci.yml` asks Nx which apps a change touches and runs only their jobs. Branch protection requires
two checks: `Check ✅` (the gate over the other jobs) and `Audit 🔒` (dependency audits, always run). CodeQL covers
JavaScript and Python. Each app is released on its own by release-please; see [docs/releases.md](docs/releases.md).
